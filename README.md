# iCoder — Bootstrap Website

A frontend learning project exploring Bootstrap 5 components, responsive navigation and multi-page layouts.

**[Open the website](https://takitamim.github.io/iCoder_Bootstrap/)**

## Run locally

```bash
python -m http.server 8000
```

Open http://localhost:8000. Bootstrap is loaded from a CDN, so its styles/scripts require an internet connection.

## Files

- `index.html`: homepage.
- `about.html`: about page.
- `contact.html`: contact-page UI.
- `assets/`: images used by the pages.

This is a static frontend exercise. Forms and account-related UI should not be interpreted as a working backend service.
